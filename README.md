# Xenogears Mass Driver

This repository contains the Windows patcher source and build contract for
Xenogears Mass Driver.

https://github.com/Project-Benjamin/Mass-Driver/releases/download/patcher/Xenogears_Mass_Driver.zip

Install video: https://youtu.be/cG3UCDvokm8

The patcher also acts as a launcher. Otherwise, you may load the "*\Xenogears_Mass_Driver\Mass Driver Game\Xenogears_Mass_Driver.bin" manually into your emulator.

## Download and use

Download `Xenogears_Mass_Driver.zip` from this repository's Releases page.

1. Extract the complete ZIP to a writable folder.
2. Open `Xenogears_Mass_Driver.exe`.
3. Browse to an unmodified USA Xenogears Disc 2 raw BIN.
4. Select **Build game**, then **Play**.

The patcher does not include the Xenogears .bin file, an emulator, or a BIOS. It reads but
never changes the source BIN.
