# DuckStation v0.1-7371 corresponding source

The Mass Driver public player bundles unmodified DuckStation v0.1-7371 from the official old-releases repository (GPL-3.0), commit b2577ef8bdaae99840874b6dae8146f0316357b4. This companion contains that complete source snapshot, the dependency source archives pinned by its Windows x64 dependency build script, and the resolved SPIRV-Cross source tag. Upstream patch files and build scripts are retained inside the main source ZIP. The original runtime is a separate installation payload. No game or BIOS is present here.

Extract DuckStation_Source.zip, then use its README, scripts/deps/build-dependencies-windows-x64.bat and scripts/windows/build.bat instructions with the upstream compiler and SDK prerequisites. Dependency archives are under dependency-source. SHA256SUMS.txt and DEPENDENCY_PROVENANCE.json identify their exact bytes and origins. The original zlib download moved; its official GitHub release mirrors the exact original ZIP. The generated GitHub zstd patch now expands its blob abbreviations by one digit; restoring the original 10-digit index line reproduces the exact upstream-pinned hash.

Preserve each component's licenses and notices. The runtime uses dynamically linked LGPL libraries, which remain replaceable within the installation's version/runtime directory; replacing an immutable payload requires bypassing the application launcher's integrity check by running the emulator directly. Upstream source and dependency sources are supplied to allow inspection and rebuilding. The project installer source companion explains the launcher, generated configuration and checks.
