# Mass Driver 1.0

1. **[Download Setup for Windows 10/11 (64-bit)](https://github.com/Project-Benjamin/Mass-Driver/releases/download/mass-driver-1.0/Mass_Driver_Setup.exe)**.
2. Install, then click **Play**.
3. When asked, select your own **untouched USA Xenogears Disc 2 BIN** and **USA PlayStation BIOS**.
