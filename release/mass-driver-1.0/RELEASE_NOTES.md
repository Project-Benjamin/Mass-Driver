# Mass Driver 1.0 (V176)

Download **Mass_Driver_Setup.exe**. Install, then choose **Play**. First launch
opens file pickers for your untouched USA Xenogears Disc 2 BIN and supported
512 KB USA PlayStation BIOS dump. The app builds a separate game copy and
remembers setup. No Python, manual patching or separate emulator installation
is needed. The public download contains no game image or BIOS.

The dungeon includes native random battles, the completed Guardian/launch route,
archive records, video and both minigames. Release QA repaired native Continue,
the north lift, early save entry and Missile Command's Triangle mapping.
A fresh final-disc Sony-BIOS New Game-to-ending run and ordinary save/cold-load
passed. Finite traversal covered all 33 fields and 66 directed connections;
separate checks covered encounters, shops, wrong answers, defeat/retry and
completed revisits. The profile suite ran **426 tests: 424 passed, two existing skips**.

The Windows installer was verified for exact clean-disc reconstruction, invalid
and missing inputs, cancellation/retry, repair, retained user data, native
startup and remembered setup. This is unsigned software tested on an existing
Windows x64 PC. Physical controller hardware, every driver configuration and
a clean Windows VM were not tested. Microsoft's prerequisite download/signature
path passed; Microsoft's installer was not executed during the audit.

Matching project, player, patcher and GPL-era DuckStation/dependency source
archives are provided alongside the binary. SHA256SUMS.txt identifies each file.
The complete source build requires the documented external extracted inputs;
it is not a turnkey clean-disc rebuild. Preserve included licenses/notices.
