# Mass Driver Dungeon 3.23 — Vierge continuity correction

V167 corrects Elly's Gear during the Mass Driver chapter. She is still
piloting regular Vierge here; El-Regulus has not entered the story yet.

## Active chapter

- Elly uses Vierge, Gear ID 2, from New Game through the world map, factory
  boarding scene, Guardian battle, post-victory reload, and return route.
- The field-376 north lift reasserts Elly/Vierge and Emeralda/Crescens before
  loading field 384. This normalizes older memory-card saves that carried the
  prior Gear-10 assignment. A savestate with field 384 already resident must
  still leave and re-enter the room so the corrected script can load.
- Field 384 names Vierge and emits exactly one Elly-to-Gear-2 assignment; it
  emits no Elly-to-Gear-10 assignment.
- Retail Vierge model/animation canonicals 2930 and 2931 are not replaced.
- Shared canonical 29 contains only the Video Disk item-name edit, canonical
  2594 contains only its description edit, and canonical 2614 is retail normal
  combat data.

## El-Regulus preservation

The completed El-Regulus work has not been discarded. It is now a dormant,
reproducible eleven-resource archive under `content/el_regulus_future/` and can
be materialized locally with:

```powershell
python tools/build_el_regulus_archive.py `
  --input-root work `
  --output work/el_regulus_future_archive
```

The archive covers Gear 10's field/world-map sprites, menu and equipment
previews, model, animations, AERODs visual and audio, command names, and both
system/live battle balance tables. None of the eight dedicated El-Regulus
canonicals are present in the V167 build.
