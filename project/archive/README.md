# Historical project evidence

[README_before_consolidation.md](README_before_consolidation.md) is the exact root README preserved before the project was organized into modules. Its dated release statements and engineering notes are evidence for those builds.

Relative paths inside that untouched document refer to its former location at the repository root.

Versioned release notes and transcripts remain under [docs](../docs/), preserving the paths and contents used by historical tests. Old build images, captured states, and audits retain their recorded identities; the consolidation does not relabel them as new releases.

Use the [current project README](../README.md) for build commands and module locations. New build receipts belong to their own `builds/<profile>/<release>/` directory.

The [original modding starter kit](xenogears_modding_starter/README.md) is retained here for reference. Current development uses `modules/` and `shared/`. Older documentation is grouped in the [documentation history](../docs/history/README.md); fixed-path regression fixtures remain in their original locations.
