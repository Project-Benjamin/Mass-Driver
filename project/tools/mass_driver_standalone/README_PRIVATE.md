# Mass Driver private standalone installation

Open the installer, select **Install**, then **Play**. Later, open the installed
`Play Mass Driver.exe`. This private package includes the game, runtime and
locally supplied firmware; no player-side patching or disc selection is needed.
The graphical installer can add a per-user Start menu shortcut. **Open folder**
shows the installation; headless verification does not create shortcuts.

Keyboard: arrows move; K (Cross) confirms choices and advances dialogue,
L (Circle) cancels, J is Square, and I Triangle; Enter is
Start and Backspace Select. Q/E are L1/R1, 1/3 are L2/R2. A standard SDL gamepad
is also configured. Escape opens the pause menu; F11 switches fullscreen.

The installation is per user and does not need administrator rights. Memory
cards, saved states and settings live in `UserData` under the chosen install
folder. Reinstalling the same content preserves them. Keep that folder when
removing or replacing an installation. Existing global emulator settings and
memory cards are not used or changed.
