# Xenogears Mass Driver

Open `Xenogears_Mass_Driver.exe`, choose your unmodified USA Xenogears Disc 2
BIN (`SLUS-00669`, raw MODE2/2352), and select **Build game**. The patch is
included in this one download. Your original BIN is read only and never changed.

The app puts verified patch data and dependency notices in a private folder
under your Windows local application data. It extracts no executable and
starts no patching helper. You do not need administrator rights.

The generated game defaults to the `Mass Driver Game` folder under your local
`Xenogears Mass Driver` application folder. Select **Choose game location**
to create it somewhere else. The app shows its full location. Allow about
1 GB of free space there. **Cancel build** safely discards temporary output;
select **Build game** again to retry.

Select **Play** to use an installed PlayStation emulator. If none is found,
choose your emulator's EXE or use an official download button. Configure your
own BIOS, controller and memory cards in that emulator. No game disc, BIOS or
emulator is included. Windows 10 or 11, 64-bit, is required.

Boot the generated CUE. Fully restart the emulator and use New Game when
checking an update; an old save state can restore old resident game code.
The app saves no emulator path or settings. A chosen custom game location
applies to this session; choose it again after reopening the app.

The app is unsigned. Its published SHA-256 identifies this exact download;
it does not replace a code-signing certificate or guarantee antivirus approval.
Keep the matching source companions and dependency notices with the release.
